# UC-11-errors Ошибки окружения

**Docker недоступен:** понятная ошибка с путём сокета и подсказкой про `--docker-host`, код выхода 3.
**Registry: 401/403/429/5xx:** различаются в сообщении; 429 и 5xx — повтор с паузой; 401/403 — деплой отменён.
**Нет прав на сокет:** подсказка про группу docker.
**macOS:** автоопределение сокета Docker Desktop.
**Общее правило:** любая ошибка до шага `up -d` не изменяет запущенные контейнеры.
