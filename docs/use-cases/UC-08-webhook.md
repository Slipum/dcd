# UC-08-webhook Триггер по вебхуку

**Актор:** registry (Docker Hub, GHCR, Gitea, Forgejo). **Триггер:** POST на `webhook.listen`.
**Поток:** 1) проверить HMAC-подпись. 2) Определить сервис по имени образа/тегу. 3) Запустить UC-02/UC-03 только для него.
**Альтернативы:** подпись неверна — 401, событие в аудит; образ не описан в политике — 202 без действия; несколько событий подряд — схлопываются в один деплой.
**Результат:** обновление за секунды после push.
