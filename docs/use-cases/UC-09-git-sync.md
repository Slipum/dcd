# UC-09-git-sync Изменение политики или compose в Git

**Актор:** daemon/оператор. **Триггер:** новый коммит в отслеживаемой ветке.
**Поток:** 1) fetch в кэш. 2) Проверить новую политику (validate). 3) Показать/применить diff стека: изменённый compose, границы версий. 4) Применить по UC-03.
**Альтернативы:** конфликт или недоступный Git — работаем на последней валидной версии; невалидная политика — отклонена.
**Результат:** хост соответствует Git.
