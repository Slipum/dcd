# UC-02-check-diff Проверка обновлений и diff

**Актор:** оператор. **Триггер:** `dcd check` / `dcd diff`.
**Поток:** 1) загрузить политику (и обновить Git-кэш). 2) Для каждого сервиса получить digest манифеста для платформы хоста. 3) Сравнить с digest из labels запущенного контейнера. 4) Вывести таблицу: сервис, текущий, кандидат, действие (update / pending approval / up-to-date).
**Альтернативы:** registry недоступен или нет прав — сервис помечается error, остальные проверяются; контейнер не запущен — состояние missing.
**Результат:** состояние хоста не меняется (dry-run).
