# UC-01-init-validate Создание и проверка политики

**Актор:** оператор. **Триггер:** `dcd init`, затем `dcd validate`.
**Основной поток:** 1) init создаёт шаблон policy.yaml и JSON Schema. 2) Оператор правит файл. 3) validate проверяет схему, ссылки на registry, существование compose-файла, согласованность healthcheck/strategy.
**Альтернативы:** файл уже есть — init отказывается без `--force`; blue_green + healthcheck none — ошибка валидации; неизвестное поле — ошибка с номером строки.
**Результат:** код выхода 0 или список ошибок. Ничего на хосте не меняется.
