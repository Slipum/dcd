# UC-07-daemon-polling Daemon: опрос registry

**Актор:** systemd/launchd. **Триггер:** `dcd daemon`.
**Поток:** по `poll_interval` каждого сервиса выполняется UC-02 и, для `auto`, UC-03. Сигнал SIGHUP — перечитать политику; SIGTERM — корректно завершить текущий деплой и выйти.
**Альтернативы:** некорректная политика при SIGHUP — остаётся старая, ошибка в логе; ошибки registry — экспоненциальная пауза с лимитом.
**Результат:** актуальное состояние без участия человека.
