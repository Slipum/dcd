# UC-10-status Статус

**Актор:** оператор. **Триггер:** `dcd status`.
**Поток:** показывает для каждого сервиса: текущий digest, previous, состояние (healthy/unhealthy/missing/pending), время последнего деплоя (если включена история), блокировки.
**Результат:** одна таблица, формат `--output json` для скриптов.
