# UC-03-apply-auto Автоматическое обновление (recreate)

**Актор:** оператор или daemon. **Триггер:** `dcd apply`, опрос, вебхук.
**Предусловие:** решение из `idempotency.md` = Update (`approval: auto`, кандидат отличается от текущего, не rejected, блокировка стека свободна).
**Поток:** 1) взять блокировку. 2) Записать детерминированный override: `image@digest`, labels `dcd.digest`, `dcd.previous-digest`, `dcd.tag`. 3) `docker compose pull`, затем `up -d --no-deps <service>` (соседние сервисы не трогаем). 4) Ждать healthcheck (UC-05). 5) Снять блокировку, записать историю (если включена).
**Альтернативы:** pull упал — деплой не начат, текущий контейнер цел; healthcheck не пройден — UC-05; процесс прерван посреди деплоя — повторный запуск сходится к целевому состоянию (UC-13).
**Результат:** контейнер запущен на новом digest, labels обновлены.
