# UC-13-idempotent-rerun Повторный запуск без изменений

**Актор:** оператор или daemon. **Триггер:** `dcd apply` повторно, опрос без новых образов, перезапуск daemon, повторный вебхук.
**Поток:** состояние сервиса и кандидат сравниваются по правилам `idempotency.md`; результат NoOp / Skip / Wait / Pending для каждого сервиса.
**Гарантия:** ноль изменяющих вызовов Docker (`pull`, `up`, `stop`, `rm`), нулевая запись override, код выхода 0.
**Альтернативы:** предыдущий запуск оборвался посреди деплоя — состояние контейнера и labels не совпадают, утилита завершает деплой (сходимость), а не запускает новый; контейнер был создан не утилитой (нет labels) — один раз сопоставляем по RepoDigests, при совпадении NoOp, иначе один recreate с проставлением labels.
**Результат:** любое число повторов даёт то же состояние, что и первый.
