# UC-04-manual-approval Ручное подтверждение

**Актор:** оператор. **Предусловие:** `approval: manual`.
**Поток A (TTY):** `dcd apply` показывает diff и спрашивает y/N; при y — UC-03.
**Поток B (daemon):** daemon обнаруживает кандидата, ничего не применяет, статус pending виден в `dcd status`; оператор вызывает `dcd approve <stack>/<service> [--digest sha256:...]`; approve заново получает кандидата (или сверяет с указанным digest) и запускает UC-03.
**Альтернативы:** кандидат сменился между проверкой и approve без `--digest` — применяется актуальный и это явно выводится; с `--digest` несовпадение — отказ.
**Результат:** обновление только после явного решения человека.
