# UC-12-concurrency Параллельные запуски

**Сценарий:** daemon уже деплоит стек, оператор запускает `dcd apply`.
**Поток:** блокировка на стек (файл-лок в runtime-директории). Второй процесс получает отказ и сообщение, кто держит блокировку.
**Альтернативы:** процесс умер с блокировкой — лок снимается ОС (flock), деплой, прерванный в середине, обнаруживается по несоответствию labels/контейнера и сообщается в status.
**Результат:** один деплой на стек одновременно (FR-17).
